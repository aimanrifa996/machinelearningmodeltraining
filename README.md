# Machine Learning using Scikit-learn

## Project Overview
This project demonstrates a basic Machine Learning workflow using Python and Scikit-learn. A Decision Tree Classifier is trained to classify breast cancer tumours using the Breast Cancer Wisconsin dataset.

## Tasks Completed
- Loaded and explored the dataset.
- Split data into training and testing sets.
- Trained a Decision Tree Classifier.
- Generated predictions.
- Evaluated model performance using accuracy, precision, recall, and F1-score.
- Visualized results using a confusion matrix.
- Tested an individual prediction.
- Saved the trained model.

## Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- Joblib

## Files
- `first_machine_learning_model.ipynb` – Jupyter Notebook containing the complete implementation.
- `breast_cancer_model.pkl` – Saved trained model.

## Conclusion
Successfully implemented a beginner-friendly Machine Learning classification project and understood the basic workflow of model training, testing, prediction, and evaluation.
